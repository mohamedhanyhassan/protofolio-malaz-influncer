# بورتفوليو حملات ملاذ

موقع ثابت (Static) يشتغل على GitHub Pages بدون سيرفر.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الموقع نفسه: الصفحة الرئيسية + صفحة لكل حملة (`#c-اسم-الحملة`) |
| `admin.html` | لوحة التحكم: إضافة الحملات واللوجوهات واللينكات والأرقام |
| `data.js` | كل البيانات — ده الملف الوحيد اللي بيتغيّر |
| `assets/` | التصميم والكود |
| `logos/` | (اختياري) لوجوهات البراندات كملفات |
| `videos/` | (اختياري) فيديوهات MP4 للتغطيات |
| `fonts/` | (اختياري) حط `thmanyah-bold.woff2` و`29lt-azer.woff2` وهيشتغلوا تلقائيًا |

## الرفع على GitHub Pages (مرة واحدة)

1. اعمل Repository جديد (مثلًا `malaz-portfolio`) وارفع كل محتوى الفولدر ده.
2. من **Settings → Pages** اختار **Deploy from a branch** ← `main` ← `/ (root)` ← Save.
3. بعد دقيقة الموقع هيبقى على: `https://USERNAME.github.io/malaz-portfolio/`
4. لينك أي حملة: `https://USERNAME.github.io/malaz-portfolio/#c-binrushd-optical`

## إضافة حملة أو تعديلها

1. افتح `admin.html` من الموقع المرفوع (أو من جهازك).
2. اضغط **+ حملة جديدة** واكتب اسم البراند والعنوان ونوع الحملة ولينك البراند، وارفع اللوجو.
3. الإجماليات (المؤثرين والمشاهدات والمتابعين والتفاعل) **بتتحسب لوحدها** من أرقام التغطيات.
4. في **التغطيات**: الصق لينكات تيك توك أو إنستغرام، أو اضغط **إضافة لينكات بالجملة** والصق عمود من الشيت.
   - لو هتلصق صفوف من الشيت فيها أرقام، رتّب الأعمدة كده: `url · username · followers · views · likes · comments · saves · note`
5. التعديلات بتتحفظ تلقائيًا في متصفحك كمسودة، واضغط **معاينة الموقع** عشان تشوفها.
6. لما تخلص اضغط **تصدير data.js** وارفع الملف مكان القديم على GitHub (Add file → Upload files). الكل هيشوف التعديلات بعدها بدقيقة.

> المسودة محفوظة في متصفحك إنت بس، فالعملاء مش هيشوفوا أي تعديل غير لما ترفع `data.js`.

## صفحة الحملة

كل صفحة حملة بتتبني لوحدها من الأرقام اللي تدخّلها، بالترتيب ده:

1. **الهيدر:** لوجو ملاذ × لوجو البراند، والعنوان، وكارت المشاهدات الكبير.
   - الكلمة اللي تحطها بين نجمتين في العنوان بتظهر بالذهبي، زي: `إطلاق *حلاي كرانشي* في الرياض`.
2. **الشريط المتحرك:** الهاشتاجات وأرقام الحملة.
3. **من حقق الوصول ومن حقق التفاعل:** رسم بالأشرطة فيه تبويبات للمقاييس وفلتر لحجم الحساب.
   - بيظهر لو فيه رقمين على الأقل لنفس المقياس.
   - أعلى 5 في الإعجابات بيتلوّنوا ذهبي، لو الحملة فيها 8 تغطيات أو أكتر عندها إعجابات.
4. **تصنيف المؤثرين حسب المتابعين:** بيظهر لو مدخّل عدد المتابعين لتغطيات من فئتين مختلفتين على الأقل.
5. **التغطيات:** الفيديوهات، وتقدر تعرضها كجدول.
6. **ما تعلمناه للحملات القادمة:** تكتبه من لوحة التحكم، ولو سبته فاضي الموقع بيطلّع ملاحظات تلقائية من الأرقام.

## الفيديوهات جوه الموقع

- عمود **الفيديو** في لوحة التحكم بيوضح كل لينك هيشتغل جوه الموقع (▶) ولا هيفتح برا (↗).
- **تيك توك:** بيشتغل جوه الكارت صامت تلقائيًا، وفيه زر **تشغيل الصوت**.
- **إنستغرام:** بيظهر المنشور جوه الكارت، والتشغيل يكون بالضغط عليه. إنستغرام ما بيسمحش بالتشغيل التلقائي ولا بزر الصوت.
- **يوتيوب:** بيشتغل زي تيك توك.
- **MP4 (أفضل تجربة):** حط الملف في `videos/` واكتب مساره في خانة "فيديو MP4"، مثلًا `videos/r-co2020.mp4`. الفيديو بيشتغل فورًا، صامت، وفيه زر الصوت، وبيبان زي التصميم المرجعي بالظبط. GitHub بيقبل ملفات لحد 100MB، والأفضل إن كل فيديو يكون أقل من 10MB.
- **سناب شات:** ما عندوش تضمين، فالكارت بيعرض زر يفتح اللينك.
- **لينكات تيك توك المختصرة** (vt.tiktok.com/…): لوحة التحكم بتحاول تحوّلها للينك الكامل لوحدها، ولو ماعرفتش هتعلّمها بالأحمر. ساعتها افتح اللينك في المتصفح وانسخ اللينك الكامل اللي فيه `/video/`.
- أي حساب **خاص (Private)** أو فيديو اتحذف مش هيشتغل.

## ملاحظات

- اسم صفحة الحملة (`id`) بالإنجليزي وبدون مسافات، ويتعدّل من لوحة التحكم.
- **إخفاء** حملة بيشيلها من الموقع من غير ما يمسحها.
- `admin.html` مش محمية بباسورد: أي حد يفتحها يقدر يعدّل في متصفحه هو بس، والتعديل ما بيوصلش للموقع غير لما حد يرفع `data.js` على GitHub. لو مش عايز حد يشوفها، شيلها من الريبو وافتحها من جهازك.
